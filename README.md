## 🚀 Things I've Built

### 🧠 JPI.ai

**AI-powered visual learning**

An AI system that turns questions into dynamically generated educational animation videos.

```text
Question
   ↓
LLM reasoning
   ↓
Code generation
   ↓
Manim
   ↓
Rendered explanation
```

**Next.js · FastAPI · Python · Celery · Redis · Gemini · Manim**

---

### 👻 LostAF

**Snapchat-style Lost & Found**

A social, location-oriented lost-and-found platform designed for **campuses, tech parks, malls, and other large communities**.

Users can post lost/found items, discover nearby reports, and use AI-powered image understanding to help identify potential matches.

**React · Next.js · Node.js · MongoDB · Gemini**

---

### ⚡ Ampway

**Smart campus electric buggy tracking**

A platform for tracking **campus electric buggies** and notifying users when a buggy is approaching or available.

```text
Electric Buggy
      ↓
Live Location
      ↓
Ampway
      ↓
User Notifications
```

Built with a focus on **real-time tracking, notifications, and campus mobility**.
